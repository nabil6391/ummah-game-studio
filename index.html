Built from a real Defold port, not a docs skim

Every engine claim in this kit was paid for once already, on a shipped game.

The Defold workflows here were extracted from Beat Runner, a full port of a SwiftUI and RealityKit runner into Defold — curved procedural track, skinned characters, a GUI suite, and a live HTML5 build. The traps it hit are written into the skills as behaviour to check, not advice to consider.

That means the kit knows things a manual will not tell you: that scale on an embedded component in a .go is ignored while instance scale3 in a .collection is respected; that a # comment silently breaks game.project parsing entirely; that missing shared_state = 1 gives every script its own Lua context and presents as a rendering bug; that the wasm-web platform runs vanilla Lua 5.1 where a single goto blacks the canvas with no build error; and that a texture profile block for web can grow your archive instead of shrinking it. Each one cost hours before it became a line in a workflow.

Halal game development questions

Does it work with Codex and Claude Code?

The agent and workflow content is product-neutral and intended for both. The current installer automatically writes Claude Code’s .claude/ structure and CLAUDE.md. First-class Codex installation is not available yet.

Which engines does the halal games kit cover?

Engine-specific implementation covers Defold and browser games: HTML5, Canvas, WebGL, Three.js, Phaser and PixiJS. Broader design and QA workflows apply elsewhere when evidence permits, but this release does not claim dedicated Unity, Unreal or Godot implementation.

Can it publish to web-game portals?

Yes. Focused workflows cover Poki, CrazyGames, GameDistribution, YouTube Playables, Wavedash, itch.io and Coolmath Games, plus a shared multi-portal architecture workflow. Each integration verifies the current official SDK before changing a project.

What makes the Defold content different?

It was written from a real port rather than from documentation. The engine traps, asset-pipeline bakes, verification harness and structural guards all come from a shipped Defold game, including the web build.

What happens to files I have already changed?

The installer leaves modified installed files untouched and reports the conflict. Your CLAUDE.md is backed up before its managed block is changed.

What do I own?

A licence delivered through read access to the private kit repository, with the right to use and modify its content in your own projects, including commercial games. You cannot resell, republish or share access to the kit itself.
